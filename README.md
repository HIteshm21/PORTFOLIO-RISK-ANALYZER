# 📊 Portfolio Risk Analyzer

An interactive financial analytics dashboard built using Python and Streamlit.

## 🚀 Features

- Historical, Parametric, and Monte Carlo Value at Risk (VaR)
- Sharpe Ratio (risk-adjusted return)
- Beta calculation vs Nifty 50
- Portfolio return visualization
- Risk distribution analysis

## 🛠 Tech Stack

- Python
- Pandas, NumPy
- yFinance API
- Streamlit
- Matplotlib, Seaborn

## 📈 How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
